When Emet disputes a claim, Claude now also says what the tool output it can still see in the session shows about it, in one line per claim, and quotes the few words of output it relies on. When the output contradicts the claim, Claude says the claim was wrong and gives the value the output shows. When it supports the claim, Claude says the flag looks mistaken. When no output Claude can see settles it, Claude says it cannot tell. Claude is asked to rule from that output only, never from Emet's reason or suggested correction, and to say once that Emet's check and its own reading use only that turn's evidence, and can miss things or be wrong. It is no longer asked not to say who is right. The same holds for a report given to Claude with your next prompt. A report saved by an earlier version of the plugin and not yet given to Claude is not shown. [claude/README.md](claude/README.md#when-emet-disputes-a-claim) has the details.
