A symbolic link at a session's `pending.jsonl` or `checks.jsonl` file is no longer written through. Before, the plugin added its line to the file the link pointed to. Now the link is removed, the line is written to a new file, and the log says `pending file was a link, removed` or `checks file was a link, removed`. On macOS and Linux the two files are no longer read through a link either, and a named pipe put in their place cannot make the plugin wait.
