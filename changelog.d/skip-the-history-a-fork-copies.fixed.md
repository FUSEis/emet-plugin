A forked session no longer sends the earlier conversation again. When you fork a session (`/branch`, `/fork` or `claude --resume <id> --fork-session`), Claude Code copies the earlier turns into the new session's file. The plugin sent each of them to Emet a second time, read their reports again, and could give Claude a report on an old answer with a new prompt. Now a turn that Claude Code marks as copied, with `forkedFrom` on every entry, is not sent and its report is never read. A copied turn that the fork goes on with is sent whole. A Claude Code that does not write `forkedFrom` gets the earlier behavior: the copied turns are sent again.
