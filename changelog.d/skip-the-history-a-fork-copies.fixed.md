A forked session no longer sends the earlier conversation again. When you fork a session (`claude --resume <id> --fork-session`, `/fork` or `/branch`), Claude Code copies the earlier turns into the new session's file. The plugin sent each of them to Emet a second time, read their reports again, and could give Claude a report on an old answer with a new prompt. Now the plugin starts a fork after the copied turns, so only the fork's own turns are sent and checked. This holds when Claude Code has written the copy by the time the fork starts. A fork whose file is written later is sent as before.
