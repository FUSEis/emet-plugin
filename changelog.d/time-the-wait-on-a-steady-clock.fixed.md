The report check now counts its own waits on a clock that a change of the system clock does not move: the 300 seconds of a run, the minute with nothing to poll, the times between requests and the wait behind another watcher. Before, a system clock set forward during a run ended it early as `timed_out`, and one set back could keep it polling past its 300 seconds. Whether a report is late is still decided by the system clock, so a report read after the machine slept wakes no one and comes with the next prompt.
