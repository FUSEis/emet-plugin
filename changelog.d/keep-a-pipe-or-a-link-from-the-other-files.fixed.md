A symbolic link at one of the plugin's `*.lock` files is no longer opened. Before, the plugin took its lock on the file the link pointed to, and made that file when it did not exist, outside its data folder. Now the link is removed and the lock is taken on a new file. A named pipe put in place of `emet.log` can no longer make a hook wait: the line is given up. A named pipe put in place of one of the plugin's JSON files, such as a session's state file or `status.json`, is read as an absent file, where a pipe held open by a writer that wrote nothing ended that run of the hook with a `TypeError`. A folder in the place of such a file no longer leaves a file descriptor open on each read.
