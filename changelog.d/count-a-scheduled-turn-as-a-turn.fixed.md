- A turn that Claude Code starts on its own schedule (a `/loop` iteration, a scheduled wake-up) or for a message from another Claude session, such as a background subagent's result, is now sent as a turn of its own, and its report is read like any other turn's. Before, such a turn was added to the trace of another turn and its answer was never checked. Its prompt is sent under the same capture mode rules as any prompt, and no conversation title is taken from it. Several such messages with no answer between them stay one turn. One that follows a slash command or a shell escape that Claude does not answer is sent under its own prompt, not under the command's output.
- The notice Claude Code writes to the session file as a record, a moment after a background subagent's message was answered, is no longer taken for the start of a turn. Before, a report that arrived after it was held back as if you had started a new turn, and the next message was sent under the notice's id.
- The plugin tells these entries by fields of the session file that Claude Code 2.1.3xx writes and does not document (`isMeta` with `turnOrigin` of `scheduled` or `peer`, and `queueTranscriptOnly`).
